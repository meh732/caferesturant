================================================================================
           راهنمای جامع و دستورات کامل ساخت و خروجی تائوری (Tauri v2) برای ویندوز
                           سامانه صندوقداری و رستوران آرکا (Arka-POS)
================================================================================

این راهنما شامل تمامی پیش‌نیازها، دستورات خط فرمان (PowerShell / CMD) و مراحل خروجی گرفتن
فایل اجرایی نصبی (.exe و .msi) روی ویندوز ۱۰ و ۱۱ است.

--------------------------------------------------------------------------------
بخش ۱: نصب پیش‌نیازهای ضروری ویندوز (فقط یک‌بار انجام می‌شود)
--------------------------------------------------------------------------------

۱. نصب Node.js (نسخه 18 یا بالاتر):
   - دانلود از سایت رسمی: https://nodejs.org
   - یا با دستور winget در پاورشل (Run as Administrator):
     winget install OpenJS.NodeJS.LTS

۲. نصب ابزارهای ساخت C++ مایکروسافت (Microsoft C++ Build Tools):
   - تائوری برای کامپایل در ویندوز به کامپایلر MSVC نیاز دارد.
   - لینک دانلود مستقیم: https://visualstudio.microsoft.com/visual-cpp-build-tools/
   - موقع نصب در Visual Studio Installer، حتما تیک گزینه:
     "Desktop development with C++"
     را فعال کرده و دکمه Install را بزنید.
   - یا با دستور winget:
     winget install Microsoft.VisualStudio.2022.BuildTools --override "--passive --add Microsoft.VisualStudio.Workload.VCTools --includeRecommended"

۳. نصب زبان برنامه‌نویسی Rust و ابزار Cargo:
   - دانلود فایل rustup-init.exe از: https://www.rust-lang.org/tools/install
   - اجرای فایل و زدن دکمه 1 (Default Installation)
   - یا اجرای دستور زیر در پاورشل:
     winget install Rustlang.Rustup
   - پس از اتمام نصب، یک‌بار پنجره ترمینال یا سیستم را ریستارت کنید و دستور زیر را چک کنید:
     rustc --version
     cargo --version

۴. کامپوننت WebView2 Runtime:
   - در ویندوز ۱۱ و اکثر ویندوزهای ۱۰ به‌صورت پیش‌فرض نصب است. اگر نبود:
     https://developer.microsoft.com/en-us/microsoft-edge/webview2/

--------------------------------------------------------------------------------
بخش ۲: راه‌اندازی پروژه و ساخت برنامه
--------------------------------------------------------------------------------

۱. وارد پوشه پروژه شوید (پوشه‌ای که فایل package.json در آن قرار دارد):
   cd C:\path\to\your\project

۲. نصب پکیج‌ها و وابستگی‌های پروژه:
   npm install

۳. اجرای برنامه در حالت توسعه زنده (Development / تست قبل از بیلد):
   npm run tauri:dev
   (یا دستور: npx @tauri-apps/cli dev)

۴. ساخت فایل نصبی نهایی ویندوز (Production Build):
   npm run tauri:build
   (یا دستور: npm run build:win)

--------------------------------------------------------------------------------
بخش ۳: محل فایل‌های خروجی ویندوز (EXE و MSI)
--------------------------------------------------------------------------------

پس از اتمام موفقیت‌آمیز دستور build، فایل‌های نصبی و پرتابل در مسیر زیر ایجاد می‌شوند:

پوشه خروجی:
src-tauri\target\release\bundle\

۱. فایل نصبی MSI (مناسب نصب استاندارد در ویندوز):
   src-tauri\target\release\bundle\msi\Arka-POS_1.0.0_x64_en-US.msi

۲. فایل نصبی EXE (با NSIS Setup):
   src-tauri\target\release\bundle\nsis\Arka-POS_1.0.0_x64-setup.exe

۳. فایل اجرایی مستقیم بدون نصب:
   src-tauri\target\release\Arka-POS.exe

--------------------------------------------------------------------------------
بخش ۴: دستورات سریع یکجا (Quick Cheat Sheet)
--------------------------------------------------------------------------------

# تست و باز شدن سریع برنامه روی سیستم:
npm run tauri:dev

# ساخت آیکون‌های برنامه از فایل لوگو:
npm run tauri:icon

# خروجی گرفتن نسخه نهایی ویندوز:
npm run tauri:build

--------------------------------------------------------------------------------
بخش ۵: رفع خطاهای متداول (Troubleshooting)
--------------------------------------------------------------------------------

۱. خطای "link.exe not found" یا "Microsoft C++ Build Tools missing":
   -> ویژوال استودیو اینستالر را باز کنید و مطمئن شوید Desktop development with C++ نصب شده است.

۲. خطای دسترسی به اینترنت هنگام دانلود وابستگی‌های Rust در ایران:
   -> تنظیم DNS شکن یا ۴۰۳ روی کارت شبکه:
      DNS 1: 178.22.122.100
      DNS 2: 185.51.200.2
   -> یا فعال کردن پراکسی/VPN در ترمینال:
      $env:HTTP_PROXY="http://127.0.0.1:10809"
      $env:HTTPS_PROXY="http://127.0.0.1:10809"

۳. خطای عدم تطابق نسخه تائوری (Found version mismatched Tauri packages):
   علت: نسخه پکیج npm (@tauri-apps/api یا @tauri-apps/cli) با نسخه کریت Rust (tauri) یکسان نیست.
   راه حل ۱ (سریع‌ترین): آپدیت کردن پکیج‌های Rust:
      cargo update --manifest-path src-tauri/Cargo.toml
   
   راه حل ۲: هماهنگ‌سازی نسخه npm با پکیج نصب‌شده:
      npm install @tauri-apps/api@2.11.5 @tauri-apps/cli@2.11.5 --save-exact

۴. آپدیت کردن راست به آخرین نسخه:
   rustup update
